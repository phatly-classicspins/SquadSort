# Changelog

## 0.1.0 — 2026-10-15
- First version, taken from the Money Sort prototype's rating flow and made game-independent: `RatingPrompter`
  (once-per-install offer saved before showing, stars → store review page or feedback link, thank-you on return, a
  timeout when the game never loses focus), `RatingStoreLinks` (App Store / Google Play, native and https forms),
  `RatingKit` one-line set-up with a code-built default popup (`RatingPopup`, procedural star and rounded-box art),
  `PlayerPrefsRatingState`, `UnityRatingHost`, `RatingAppFocus`.
